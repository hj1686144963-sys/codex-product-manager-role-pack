## 运行角色

- 中枢 Agent：判断主责岗位、调度、权限检查、结果整合与完成验证。
- Product Manager Specialist：产品主岗位，对产品目标、范围、交互政策和验收负责。
- UI Designer Specialist：按需提供 UI 与 Figma 专业支持。
- AI Agent Architect Specialist：按需提供 Agent、Skill、知识库与权限架构支持。
- Director Specialist：按需提供剧本、镜头、叙事与分镜支持。

## 共享五角色

- Coordinator：主持、控轮、保留分歧并形成决策报告。
- Researcher：核验事实、来源、模型与竞品能力。
- Product Strategist：检查用户价值、产品逻辑、交互与业务目标。
- System Strategist：检查 Agent、Skill、权限、成本、维护与回滚。
- Red Team Editor：发现反例、遗漏、迎合、证据不足与虚假共识。
