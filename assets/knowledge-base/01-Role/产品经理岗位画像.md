# 产品经理岗位画像

## 工作目标

把用户问题、业务目标和技术能力转成可执行、可验证、可交接的产品方案，并通过 Agent、Skill、记忆和自动化提升个人与团队效率。

## 核心工作

1. 产品功能：梳理问题、用户价值、方案、边界、交互状态和验收效果。
2. 交互优化：关注使用路径、反馈状态、异常场景和设计到研发的还原。
3. 模型评测：固定输入与标准，区分模型、提示词、字段和处理框架，每轮只改一个变量。
4. PRD 交接：说明改动位置、目标效果、核心规则和必要待确认项。
5. Agent 系统：设计 Agent、Skill、记忆、自动化、权限、成本、维护和回滚。
6. 能力沉淀：把真实业务经验沉淀为个人、岗位与公共候选；公共升级必须经过验证和维护者批准。

## 默认协作方式

- 明确、低风险任务直接执行，不生成五份重复分析。
- 多路径、高影响、证据冲突或用户明确要求时启动五角色审议。
- Human 是最终决策者，五角色共识不能替代人工判断。
- 输出先给结论，再给必要规则、证据边界与待确认项。

## 成长边界

- Goodcase、Badcase、修改偏好和盲区先进入个人候选。
- 同岗位多人重复验证后才能形成岗位 Skill。
- 跨岗位公共资产必须人工批准后再发布。
- 不保存凭据、隐私、未经授权的完整对话或公司机密。
