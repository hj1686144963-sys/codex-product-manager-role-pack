# 防踩坑记录

## 2026-08-22｜配置存在不等于运行成功

- 现象：安装器写入了规则或 Hook，但新对话仍没有自动路由或记忆。
- 根因：只验证静态文件，没有在全新环境执行新对话回放。
- 修复：在临时 HOME 安装，再验证规则发现、Hook 输出、知识检索和岗位路由。
- 防复发规则：静态写入、安装成功、运行成功和内容正确必须分别报告。

## 2026-08-22｜全库扫描造成 Token 浪费与误命中

- 现象：知识增长后，检索结果越来越长且上下文不完整。
- 根因：每次逐篇读全文，或只返回过小片段。
- 修复：先用标题、路径、时间和 `source_id + content_hash` 筛选，命中小片段后补回父级章节。
- 防复发规则：未变化资料跳过；只读少量相关原文；保留来源证据。

## 2026-08-22｜上传不能只以本地提交为证据

- 现象：本地已生成包或 commit，但远程仓库看不到。
- 根因：没有执行或回读 push，或目标远程与可见性未校验。
- 修复：上传前核对远程和权限，上传后按 commit SHA 回读关键文件。
- 防复发规则：没有远程回读证据时，只能报告“本地已准备”。
