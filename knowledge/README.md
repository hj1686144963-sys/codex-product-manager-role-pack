# 可直接读取的共享知识目录

GitHub 上保留原始文件夹，而不是只保存 ZIP。AI 和人都可以按目录读取、比较和引用规则；ZIP 仅用于一次性下载和离线安装。

- `company/`：公开或公司公共规则。本公开包只放可公开模板。
- `roles/product-manager/approved/`：已批准的产品岗位知识。
- `roles/product-manager/candidates/`：待审查候选，不进入默认检索。
- `roles/product-manager/evaluations/`：岗位评测说明与结果。
- `projects/`：项目知识结构模板，不放真实公司私有项目。
- `people/`：个人空间说明；私人内容放各自 Private 仓库，不进入本公开仓库。
- `templates/`：知识对象模板。
