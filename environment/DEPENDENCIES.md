# 依赖说明

## 必需

- macOS、Windows 或 Linux
- Python 3.9 或更高版本
- Codex 桌面端或可读取本地文件、Agent 和 Skill 的 Codex 工作环境
- 一个可写的 Markdown/Obsidian 知识库目录

## 可选

- Obsidian：用于人工浏览本地知识库，不是运行 Hook 的强依赖。
- Git：用于版本管理、备份和团队协作。
- 飞书、Figma、浏览器等连接器：按实际任务授权；本包不内置账号或组织权限。

## 禁止打包

密码、API Token、Cookie、SSH 私钥、浏览器登录态、个人聊天全文、公司机密和未脱敏的个人数据。
