# Skill 生命周期与回归规则

## 状态

- `candidate`：新候选，只能试用，不能替换稳定 Skill。
- `active`：当前正式使用。
- `deprecated`：进入迁移期，保留兼容入口并指定 successor。
- `retired`：停止路由，但保留版本与回滚记录。

## 新旧 Skill 替换

1. 新 Skill 先以新名称或新版本进入 candidate。
2. 对岗位评测集运行基线和新版本，比较正确知识命中、错误项目引用、个人偏好污染、输出正确性和上下文字符数。
3. 只有核心用例不退化且目标指标改善，才允许成为 active。
4. 旧 Skill 先标记 deprecated，并保留 successor 和至少一个回滚版本。
5. 确认没有旧任务依赖后再 retired；禁止直接删除。

## Skill 合并

只有触发范围、输入输出和权限边界高度重叠时才合并。合并后必须重新运行两个旧 Skill 的全部评测集；如果合并使触发变模糊或上下文明显变长，应保持两个小 Skill，通过路由协作。

公共发布仍需维护者人工确认，自动化只能生成候选和评测报告。
