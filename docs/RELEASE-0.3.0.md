# 0.3.0 Beta｜中枢路由版

这是一次架构级升级，不是 0.2.0 的局部补丁。旧版继续保留在 Git 历史与旧发布说明中；本版本通过独立分支 `agent/v0.3-central-routing` 开发和验证。

## 核心变化

- 中枢 Agent 先运行 `TASK_JUDGE`，再把任务交给主责岗位。
- Product Manager Specialist 成为产品任务主责，对产品目标、范围和验收负责。
- 产品经理发现专业缺口时，通过 `SUPPORT_REQUEST` 申请 UI、AI Agent 架构师或导演支持。
- 独立专业任务由中枢直接路由，不强制先经过产品经理。
- 五角色变为一套共享内核，通过岗位 Overlay 切换专业视角。

## 保持不变

- 产品经理仍是本包的核心岗位。
- 公共能力仍需维护者确认后才能发布。
- 外部写入、删除、发送和权限扩大仍需正常授权。
- 本地知识检索、父级上下文、增量去重、安装和回滚继续保留。

## 不包含

私人 Vault、个人习惯、公司内部资料、个人项目、聊天记录、Spark、Dashi、Ponytail 和未批准的个人 Skill。

## 发布前验证

静态验证通过后，必须在全新 Codex 任务中真实回放纯产品、产品申请 UI 支持、独立 Agent 架构三个场景。未完成真实回放前，本版本保持 Beta。
